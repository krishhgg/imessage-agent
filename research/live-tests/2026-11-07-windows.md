# Window server and AX counts for Messages (2026-11-07)

Read-only probes from the maintainer's shell (no Apple Events, no titles or window names read). Messages was hidden, not active.

- AXWindows on Messages: 1 window. AXSubrole, AXMinimized and AXFullScreen all return -25205 while hidden.
- CGWindowListCopyWindowInfo with optionOnScreenOnly: 0 Messages windows.
- CGWindowListCopyWindowInfo with optionAll: 5 Messages windows, all layer 0. One is the real window, 1024 x 768 at x -1268 (off screen). Four are 1512 x 33 at (0, 0), the size of the menu bar (screen 1512 x 982, visible frame 949 tall).
- Every app with windows has the same four 1512 x 33 layer-0 strips. They look like per-Space menu bar windows on macOS 26.

What this means for the code:
- "Any layer-0 window from optionAll" is true for every running app with a menu bar. `hasNormalWindow` (MessagesApp.swift:158), which feeds the earlier front app's `hasWindows` for focus restore, is therefore always true.
- A real-window test on optionAll needs a size floor, for example at least 100 x 100, to drop the menu bar strips.
- Not yet measured: what AX and optionAll show with a Messages window on another Space or full screen in its own Space. That needs the maintainer to move the window.
