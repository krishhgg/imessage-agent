## Test 2, third try (Messages hidden by the tester)

- Cause: the hidden rule's one-window test. AX listed 1 window, the chat window. The full window list had 2 real windows (layer 0, both sides at least 100): the chat window and the 500 x 500 one, so the larger count was 2 and the rule said busy.

Its title is empty, it was never on screen while Messages showed its chat window, AX doesn't list it, and `CGSCopySpacesForWindows` puts it on no Space. The chat window is on Space 1. The four menu bar strips are on no Space too.
- Fix: PR 7 counts, for that test only, the real windows the window server puts on a Space (docs/BUILD-PLAN.md entry 51). A read-only probe that runs the bridge's own `LiveMessagesApp.state()` and `WindowRules.decide` from the fixed build gave, hidden: AX 1, real windows 2, on a Space 1, `proceed`.
